# Optional R verification export

**Status** — Proposed for review. Supersedes the regression round-trip proposal. Based on local v119.0.0 at `2060cbc`.

A user can view, copy, or save a standalone R script from a StatCraft result. Running the script is optional. It computes independently from its included source data and reports the settings and results a user needs to compare. Verification ends with R output. The standalone R Workbench remains a regular editor and console.

The current result toolbar and output menu already expose R code. Both paths in `modern_app.py` pass the active worksheet to the translator. The translator's broad regression branch calls `lm()` for multiple model types and uses the default confidence level. Its general fallback creates exploratory summaries and plots. The checkout also still contains mode-switch code that loads a result into the Workbench and a legacy Apply Predictions handler. The current product direction is explicit export from the selected result.

For this increment, certify verification for ordinary least squares with numeric predictors and the standard intercept. Both the saved and copied Base R script must run with Base R alone. Include the model confidence level, actual complete-case sample count, estimates, and confidence intervals. Preserve the order and values of included observations. Bind the result to its source worksheet. A stale result should ask the user to rerun in StatCraft before generating verification code, since the exporter has current data rather than the historical data snapshot. If the source is unavailable, report that directly. For other procedures, retain existing R output where available and label it as exploratory until parity has been verified. Keep the optional tidyverse and worksheet data export options available with clear labels.

For acceptance, fit a two-predictor regression on worksheet A at 90% confidence, with missing values in the response and in a predictor on different rows. Give a source column a name containing spaces and an apostrophe. Activate worksheet B with the same column names and different values, select A's result, and save its Base R script. Run that script in a fresh R process and compare the estimates, sample count and confidence interval endpoints with StatCraft. Then edit A and confirm that export asks for a rerun. Switching to R Workbench must leave an existing script intact.
